- Strongly prefer invoking tools to add dependencies / generate boilerplate, rather than hand-writing versions and boilerplate. `npm install` rather than editing package.json, `npm create convex@latest` rather than writing the files yourself, etc.
- **Controlled inputs with real-time state**: Never bind an input's `value` directly to Convex query state and call a mutation on every `onChange`. The server roundtrip causes the input to fight with the user's typing (cursor jumps, characters disappear). Instead, use local state with debouncing—update local state immediately for responsiveness, then sync to the server after a delay (e.g., 500ms). Only accept server state updates when the user isn't actively editing.
